# Genshin existing material text production slice

The explicit scope `genshin-independent-existing-material-text-v1` accepts one existing material and one existing nonempty display leaf: `name`, `nameEn`, `source` or `sourceEn`. Acquisition editing requires the controlled published editing baseline established by the source sync; historical intake and structural-review classification keep the original protected-source policy. Acquisition text (`source`/`sourceEn`) is distinct from immutable CMS `sourceRecord` provenance. Membership, order, identity, rarity, categories, media, recipes, quantities, relationships and fields not rendered by the material page remain outside this slice.

The compiler preserves complete published A (115 sources). Both candidate and compatible recovery require complete Genshin material dependencies. Every locale collection and material detail receives source-derived name, canonical, robots and navigation assertions; the edited detail additionally checks the actual acquisition text, including the current Japanese fallback to English. The build, sealed bundle, immutable previews and public production acceptance reopen these assertions.

The fixed desktop executor retains the historical Genshin release policy identifier for compatibility. Its frozen scope selects the character or material pair contract; a request cannot inject a scope or transport. It requires live approved CMS bytes, an installed application ancestor, exact full CI and the current complete owner topology. Only `gachia-game-genshin` may receive production traffic changes. The current source reader accepts verified intervening NTE, Main, Azur and runtime history without substituting checkout data for A.

The first pilot translates the existing `teachings-of-freedom.sourceEn` weekday text from `Domain: Mondstadt (周一/四/日)` to `Domain: Mondstadt (Monday/Thursday/Sunday)`. Search projections contain material names only, so this acquisition-text edit must preserve their values. Platform aggregates contain no material acquisition text and must likewise remain exact. The production completion and final source index, rather than this document, establish actual deployment.
