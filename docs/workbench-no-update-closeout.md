# 无需更新任务闭环交付说明

## 适用范围

本机手动工作台的 HI3 任务，经核对发现现有资料已覆盖全部已记录事实时，可以结束为“无需更新”。
不修改网站、其他游戏内容或发布流程，不需要数据库 schema 升级。

## 使用方式

在任务卡展开“核对后无需更新：结束任务”，填写理由、已核对的资料路径/实体/覆盖情况、记录者及身份类型。
代理身份必须记录授权依据；身份为自报审计信息，不是人工身份认证或发布批准。
确认后保存结束记录及审计事件，原任务快照不变。重复相同请求返回原结果，不重复记账。

条件：此证据已有事实且全部已确认，任务没有修订。任务、事实、已配置内容扫描或代码基线上下文变化时，拒绝陈旧请求，须刷新核对。
结束前必须成功读取HI3角色、武器、材料、攻略四类源文件及公共镜像，八个文件摘要齐全且四组镜像一致；扫描报告存在明确失败项时拒绝结束。未覆盖项保持未覆盖，不当成通过，也不一律当失败。
结束记录保存本次八文件摘要及覆盖边界。此门禁不覆盖其他数据集、页面代码、翻译/事实语义或生产状态；自由文本“内容核对”是操作者声明，不是机器语义验证。commit与dirty布尔也不证明整个脏工作树字节未变化。
缺失或不完整扫描同样拒绝结束。已成功结束请求的相同重试仍返回原历史结果，不重复写入；历史结论的当前有效性另按最新扫描评估。
结束后不能再创建修订；已有修订的任务必须另行处理，不允许直接结束而遗留已接受草案。
后续上下文变化会显示历史结论已过时，不自动重开。当前版本不支持同一证据任务重开，不得通过修改数据库绕过。

## 回归与验收

在已有依赖环境执行无需 HTTP 服务的定向测试：

```sh
cd apps/admin
node --import tsx --test tests/batch-lifecycle.test.mjs
```

浏览器回归需现有 Playwright 浏览器，启动一次临时工作台并创建合成数据；需事先明确允许该执行范围：

```sh
cd apps/admin
node --import tsx tests/batch-lifecycle-browser.mjs
```

测试正常或失败退出时关闭服务并清理合成数据；强制终止仍需人工确认进程退出。
浏览器只允许临时工作台同源请求，所有第三方请求拦截。测试不会读取日常库或启动 Next。
此浏览器脚本不在默认 test 通配符内，不代表 CI 自动运行；离线 test 文件在默认集合内。

已完成限定验收：26项事实/修订/恢复/生命周期回归通过，桌面1440与手机390真实UI操作及刷新持久化通过。
另已完成真实固定备份的新私有目录只读恢复检查；不等于真实恢复库应用运行、草案文件系统恢复或覆盖切换。

## 发布边界

仅工作台本地代码交付；不需要部署主站、Router 或游戏 Worker，不包含依赖、锁文件、数据库、令牌或凭据。
工程提交/推送仍可能触发仓库现有 CI 或 Cloudflare 自动构建，不应把“无需生产部署”当作“无云写入副作用”。
