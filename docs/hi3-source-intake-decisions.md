# HI3 官方采集接入：已实现边界与待定扩展

日期：2026-10-10。状态：国际服固定官方公开来源的手动采集首版已实现并验证；更广来源、定时任务和保留期限待定，不授权生产操作。

2026-10-12决定补充：内容审核由本任务代理负责并如实记录代理身份，不再逐字段等待用户；来源不足不能强行确认。外部AI暂不接入，Docker继续暂缓，清理仅先列候选/影响，实际删除和正式上线单独批准；保留期限未定、不自动清理。本授权不扩大来源、请求预算或定时任务范围，详见主文档16.6。

## 已知边界

- 现有 HI3 攻略包含“全球服官方 9.0 更新公告”资料，但不能据此把全部 HI3 数据默认归为全球服，也不能由页面显示语言推断服务器。
- 工作台支持手动证据导入及固定国际服官方来源按钮采集；来源分类为官方声明仍需核验身份与适用范围。审核可由获授权代理执行，但必须如实记录代理身份，不能伪称人工。
- 官方采集结果必须保留为待核验证据，不能直接修改内容或确认为事实。

## 确认后的实施顺序

1. 将已批准来源和服务器保存为受约束配置，禁止自由 URL 抓取；校验 HTTPS、端口、DNS/IP、重定向和私网地址，防止 SSRF。
2. 实现来源健康记录：从未采集、成功无变化、成功有变化、解析失败、访问失败、长期失联，以及最后成功时间。
3. 使用固定解析适配器提取正文，保存来源、获取时间、服务器、正文摘要和内容指纹；没有正文或解析失败不得显示“无更新”。
4. 通过本地固定响应测试去重、429、超时、超限、恶意重定向与提示注入；外部正文只作为数据。
5. 在明确许可范围内执行一次真实采集，再进行真实公告到人工审核草案的闭环验收。

后续确认仅针对扩大来源/请求范围、周期任务、保留清理等尚未实现或批准的扩展，不将已实现首版重新标为未开始。

## 已实现的受限手动采集切片

用户选择国际服并要求继续剩余任务后，按公开、无登录、人工触发的保守边界实现固定来源采集。未启用周期任务，也未扩大至其他服务器。

- 浏览器核对官网 Global 英文 Latest 列表及公告 165770 正文。官网脚本明确使用 `sg-public-api-static.hoyoverse.com/content_v2_user/app/5fcd2aa439ca4aea/getContentList`，参数为频道 514、英文 en-us。
- 一次请求只取第一页最多 3 条；接口已含正文，无需额外访问详情。上限 2 MiB、请求 15 秒、DNS 5 秒，固定域名/路径/参数，拒绝重定向、私网 IPv4 及 IPv6，连接固定已校验 IP，保留 TLS 域名校验。
- 手动点击前再次显式确认；60 秒冷却、单进程单并发，无自动重试；429 Retry-After 延长冷却。
- SQLite v9 保存当前来源状态与追加的每次运行快照；解析失败/访问失败不算无变化，超过 7 天未成功检查单独标记。旧正文仅保留为历史快照。
- 原始 HTML 只按文本显示，未自动生成事实、任务、代码或发布。将选定片段交给现有证据审核流程仍是下一切片。
