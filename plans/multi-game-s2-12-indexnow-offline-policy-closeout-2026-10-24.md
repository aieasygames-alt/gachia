# S2.12 IndexNow 离线计划与外发入口收敛

日期：2026-10-24，Asia/Shanghai。基线：`f028248`；分支：`codex/multi-game-s1-release-safety`。

## 1. 阶段结果与边界

承接 S2.11 的旧 IndexNow 清单风险，审查两个 CLI、认证 API、server-only helper 和实际调用关系，完成统一的离线候选计划及显式外发暂停。该改动不是可用生产发送器，也不是官方内容认证、索引恢复、旧提交撤销或全站事实审核完成。

本批只在隔离工作树开发、本地验证并提交；没有向搜索引擎或生产站点发请求，没有 push、部署、Actions、数据库改动、登录恢复、Worker 拓扑变更、遥测或历史文件删除。编译 API 验收只使用合成令牌和回环地址，不读取生产 secret。

两个事实 holds 保留原绑定。暂停是本站发现/推广流程的保守选择，不声称 IndexNow 协议不允许 noindex、移除或删除通知。移除用途需单独设计，本批没有实现。代码未部署，不能声称现有生产 API 已暂停或搜索引擎已有状态改变。

## 2. 审计发现与实施决策

修改前四份完整源、一次性保护清单及只读聚合发现见 [来源决策档案](../reports/content-integrity/s2-12-source-decisions-2026-10-24.json)。完整操作、计划字段及恢复条件见 [IndexNow 维护说明](../docs/indexnow-offline-planning.md)。

| 入口 / 风险 | 本批实现 |
|---|---|
| SEO 手工脚本有旧国际服角色/攻略/下载地址，域名相同即可外发 | 历史候选集合完整留存并可比较；默认输出离线计划，`--submit` 明确拒绝，不暗示候选已审核 |
| 新增模板脚本会把一个共享 version 模板乘以全部游戏/语言，且无 dry-run | 移除 Git 扫描与自动 URL 展开；要求显式候选，使用同一个计划入口，也不再依赖直接 Node 载入 TS 包的脆弱路径 |
| API 的 Bearer 认证只证明调用方持有令牌，不证明事实/索引批准 | 保留认证与输入校验；合法认证请求返回暂停 503、`ok=false`，不返回伪“通知成功”，不调用外部端点 |
| helper 有自己的宽松 URL 归一化并可调用站内 API | 保留 async/void 接口但只验证和记录暂停；混合非法批次整体拒绝，不悄悄丢弃非法值后发送剩余部分 |
| 多套域名校验接受 query/fragment/凭据等非规范形式 | 共用纯 JS policy 和声明文件，严格限制生产三语言页面路径，拒绝含糊归一化，无环境变量或 force 绕过 |
| sitemap 可能落后于正文，主站清单也不覆盖独立 owner | 仅比较显式本地 XML urlset；标准解析器验证、记录摘要；输出命中/未命中/未评估，但所有候选仍不可发送 |

未修改 public key 文件或生产 secret 要求。未增加一套 CMS、Worker、自动化任务或默认候选档案；离线计划默认输出终端，需留档才显式保存，避免重复维护和无控制的磁盘增长。

## 3. 新增与兼容行为

- `indexnow:seo-updates -- --priority` 和 `--dry-run` 均只输出计划。原有优先集合由测试与归档代码在隔离 VM 中比较相等，不执行旧发送函数。
- `indexnow:new-pages` 必须提供 `--path` 或 `--url`；空输入、未知参数、缺值以及任何 `--submit` 均非零退出。新增源码、游戏注册项或路由开关不是公共 URL 的存在证明。
- URL 原始数量上限 10,000，先验证再去重。拒绝凭据、显式端口、query/fragment、点段、编码路径、重复/尾斜杠、其他主机和非页面地址；保守 ASCII 路径约束以后需经测试显式扩展。
- 可重复传入 `--sitemap`。每文件最多 10 MiB / 50,000 个 URL，最多 16 文件；拒绝错误命名空间、根 sitemapindex、DTD/entity、非规范 loc、文件内/跨文件重复地址及缺失文件，不使用正则提取 loc。
- 快照只记录本次读到的路径、摘要和 URL 数。没有自动抓取、递归发现或正文检查；单份主图的未命中可能属于未提供的独立 owner，命中也不代表当前线上或事实合格。
- API 缺 secret 503、错 Bearer 401、非法 JSON/URL 400；合法输入统一暂停 503。helper 正常 resolve 只表示兼容调用结束，不是提交成功。

本批不改变 sitemap 或游戏事实输入，实际本地主图与 S2.11 及预渲染的 4,347 条集合相等（zh 1,527 / en 1,524 / ja 1,296），根图与 owner 不变。最终 fixture XML 用于真实 CLI 计划：192 条历史候选中 130 条命中、62 条未命中；后者包含未提供独立 owner 清单的页面，不能直接判作 62 条坏 URL。全部 192 条仍不可发送。另验证无快照的显式候选为未评估，以及显式目录候选命中但仍未批准。

两个 CLI 的 submit、未知参数和空输入六种实际进程调用均以 1 拒绝，fetch 陷阱没有被触发。开发中曾在构建正在替换 `.next` 时读取不存在的 XML，解析器按缺失文件拒绝且没有 HTTP；最终改用完成验收后保存的稳定 XML，没有添加静默回退。此项中间观测在报告保留，不作为最终计划证据。

最终产物 3,148 份普通文件、108,386,950 字节，另记录内部符号链接及组合树摘要；编译回归在同一产物上完成。实际查看最终手机历史目录和桌面纠错详情，既有文字占位和审核说明可读，未观察到正文裁切；本批没有前端设计变更，也不声称逐张查看所有语言截图。

编译端点字符串检查只是防旧 sender 误启动的回归保护，不是通用网络沙箱。测试的无外发结论由移除运输实现、fetch 拦截单测、真实 CLI 进程和仅回环 API 验收共同支持，不扩写为全站无网络访问。未把快照摘要或固定 Worker 入口哈希称为生产封存证明。

## 5. 只读聚合发现与下一阶段

本批材料与兑换码 raw 都为空，但不能据此认定“没有该系统”或页面已安全：

1. 国际服兑换码页仍可达 `RocoRedeemHub`，独立于空数组，展示旧测试日期、CBT/平台/奖励类别、“当前有效码 0”与官方来源背书；当前本地主图仍包含该 URL。**下一批最高优先级是完整归档并纠正该消费者及元数据/推荐/索引边界**，而不是让本批计划替它批准。
2. 国际服物品的通用 data 导出为空，Web item adapters 没有 roco case，但通用 items 页面仍有 Coming Soon 回退。核心 `items=false` 不证明直达一定 404，须专门验收 HTTP/metadata/静态参数。
3. 两个 held 文件、原始分发与静态资产、不可达旧首页文案仍未完整结案；原神 strict 迁移、全 owner 云端及回滚验收和独立存储治理继续保留。

恢复 IndexNow 外发另行立项：需要生产版本/全部 owner/真实 HTTP 和内容审批、显式用途、批准及逐端点发送结果；不得只切标志或关闭 holds 自动启用。回退默认保留暂停并前向修复，不单独恢复旧发送器、模板展开或宽松 URL 校验；本批未执行云端回滚。
