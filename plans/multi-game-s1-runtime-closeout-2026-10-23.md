## 1. 对上一阶段判断的修正

S1 实际观察到 OpenNext 1.20.1 拒绝 Next 15.5.18，这一事实保留。但当时将该错误进一步解释为“Next 官方已停止支持整个 15.x 系列”，证据不足。

本阶段核实：

- [Next 官方支持表](https://nextjs.org/support-policy)仍将 15.x 列为 Maintenance LTS、16.x 列为 Active LTS。页面同时保留两年期限文字，因此不能只用本机日期替代官方列出的支持版本。
- OpenNext 1.20.1 使用的 AWS helper 4.0.2 仅按首次发布日期加两年判断。
- OpenNext 1.20.13 使用 AWS helper 4.1.12；其判断还认可 Active/Maintenance LTS，即在第二个后续大版本发布前保留支持。
- [OpenNext 1.20.13 包元数据](https://registry.npmjs.org/@opennextjs%2fcloudflare/1.20.13)要求 Next `>=15.5.28 <16 || >=16.4.1`、Wrangler `^4.148.0`。因此不是只更新适配器来接受旧版本，而是同时升级到它要求的补丁版本下限。

最初试验过 Next 16.4.2。依据[官方迁移说明](https://nextjs.org/docs/app/guides/upgrading/version-16)固定 Webpack 后可以编译，但默认 `_global-error.html` 缺少预览 noindex，被既有产物检查拒绝；默认错误页和共享路由实现也发生变化。该试验未发布，Next 16 配置、补丁及临时错误页组件没有进入本次交付。

最终选择 Next 15.5.28，避免为了修复适配器判断和补丁版本问题而扩大到大版本迁移。支持结论仅对应本次查证日期与锁定版本，不是未来永久支持或全依赖无漏洞保证。

## 2. 版本与补丁策略

| 项目 | 两试点之前 | 本次交付 |
|---|---|---|
| Next | 15.5.18，自定义补丁 | **15.5.28**，独立摘要清单 |
| OpenNext Cloudflare | 1.20.1 | **1.20.13** |
| Wrangler | 4.110.0 | **4.148.0** |
| workers-types | 各自旧版本 | **5.20261006.1** |
| Node | 实测 22.22.2，根声明 >=20 | 实测 **22.22.2**，根声明 **>=22.0.0** |
| React / React DOM | 19.2.4 | 仍为 19.2.4 |

前三项使用精确版本，不使用 `^`。Wrangler 4.148.0 要求 Node 22，故同步更新根 engines；不要求修改用户全局 Node 安装。

四行补丁仍只改变 CJS/ESM layout/head router 在没有预取内容时的 initialValue fallback。新补丁文本与旧版相同，但官方分发源文件摘要已不同，不能复用旧摘要。版本选择严格限定 15.5.18 与 15.5.28，未知版本、源漂移、部分应用或未应用补丁均被门禁拒绝。未修改 React 内部实现、源映射或错误恢复机制。

主站、原神、绿梦仍解析到 Next 15.5.18 / OpenNext 1.20.1；旧补丁和旧门禁保留。当前是有期限的试点迁移状态，不是建议长期维护两套框架版本。

## 3. 工程交付

1. `require-game-runtime.mjs` 从调用应用解析实际依赖，对照精确声明和补丁摘要；不检查到别的应用就误报成功。
2. 两试点 Next build 先执行运行时检查，并保留上层指定的索引模式，不在嵌套构建中强制生产模式。
3. 发布记录加入 runtimePolicy，记录实际 Node、Next、适配器、Wrangler 和补丁状态。
4. 扩充发布测试，覆盖版本漂移、错误 Node、旧应用隔离、补丁逆向/正向应用及 fallback 行为。
5. 新增本地浏览器脚本，复用同游戏构建锁和 Worker 生命周期；验证后停止进程，不访问生产。
6. 更新 CI 路径范围、冻结锁文件、操作规程及本阶段机器摘要；没有触发远程 Actions。

锁文件不只新增两个 importer：pnpm 同时重解析了部分共享 peer 图，涉及 web、router、data 的工具链依赖上下文，例如 esbuild、terser、yaml 与 SWC helpers。因此不能声称旧应用“所有传递依赖完全未变”。已额外完成旧应用版本断言、全工作区类型检查、Router/Web 测试和主站 Next 构建。
