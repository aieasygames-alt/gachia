# S2.21：原神 Live Owner 同产物发布与正式验收

日期：2026-10-25，Asia/Shanghai。状态：**原神本批候选已经发布，限定范围生产验收通过**。不是所有游戏候选已上线、全站问题清零、CI 全绿或在线回滚演练完成的声明。

## 1. 本批结果

- 复用已有原神 staging，先验收再推广同一封存产物。只更新 `gachia-game-genshin-staging` 与 `gachia-game-genshin`，不创建 Worker，不修改 Router 开关、绑定、路由、域名或其他游戏生产版本。
- 原神采用已审查的 Next 15.5.28 / OpenNext 1.20.13 / Wrangler 4.148.0 运行时与现有补丁；不通过旧 pre-cutover 工作流重新切流。
- 原神 XML 从 1602 变为 1572，只移除 30 个缺少完整日文正文的攻略索引 URL。这些页面仍为 200，显示原文阅读提示、`noindex/follow` 和实际阅读语言；不删除攻略内容。唯一完整日文攻略 `lightrace-wish-phase-ii-faq` 继续索引。
- 修复材料清单非数组 JSON 导致渲染崩溃，以及浏览器拒绝存储/配额不足导致未处理异常。保留原存储键、合法旧数组和未知材料 ID，存储不可用时允许内存内操作并明确提示不会持久化。
- 原神直连 `workers.dev` 域名增加运行时防索引。staging 与生产使用相同生产构建，不靠重新构建 preview 包来获得 noindex。

## 4. 回退与过程中保留的失败

旧版本在生产推广后仍可由 API 读取。另将旧权威 Worker 模块与新旧静态资源并集组合，加上直连域名防索引包装，完成本地 HTTP、旧版 1602 条 sitemap 和全部 160 条资源路径验证。

**这不是云端回滚演练，也不是自动批准的生产回退配置。**旧渲染器会恢复原有语言策略及 planner 行为；原始旧版本资产绑定也不能保证包含新 chunk。实际回退必须单独核对目标与资源兼容性，不能只凭旧 UUID 可读就执行。未做不可逆数据库或账号数据迁移。

| 原始阻断/失败 | 原因与处置 |
|---|---|
| 历史上传数量与静态数量不同 | 上传总数不等于 JS/CSS 清单；只捕获实际登记的 41 个静态文件，不声称完整云端清单。失败日志保留。 |
| 本地模拟 Host 首轮未命中 | Node fetch 未实际发送自定义 Host；改为仅本地使用原生 HTTP Host 探针，域名防索引真实复验通过。 |
| 封存完整性拦截 `.wrangler/tmp` | Wrangler 将临时目录写在配置旁。保留原封存与失败记录，从固定清单恢复相同摘要的内容；工具改为在封存外生成执行配置。没有加入忽略目录放松校验。 |
| 无 JS 的脚本失败被普通失败处理 | 记录到精确 `csp`，只在明确关闭 JS 的模式登记为预期行为；其余脚本、CSS 和网络失败照常阻断。 |
| 跨 owner 首轮找不到品牌导航 | calculator 本身没有公共 Header；改在确有 Header 的游戏主页验证跨 owner 导航，calculator 仍单独验证工具功能。缺少导航列为 UX 后续项。 |
| 生产首轮未知路径 owner 断言错误 | 未知一级路径按合同属于 Main，而非原神。补充 Main 未知路径与原神未知详情两类 404，完整重新执行生产 HTTP 与浏览器检查；不修改 Router、不重发。 |
| 收尾 Cloudflare API 401 | OAuth 到期；只读刷新后重做最终快照与绑定对账，没有再次部署。 |

首轮失败不改写成成功；最终通过记录单独保存。上述无 JS 事件不能拿来解释此前 Main 正常 JS 请求失败；Main 原 CI failure 和未知根因仍保留，S2.20 的成功只读复验凭据不变。

## 6. 未关闭事项及下一批顺序

1. **异环、绿梦运行时/资源候选仍未发布。**分别恢复旧来源、检查本地数据兼容和明确不盲目增加 Worker 的预览/放行方案，再逐 owner 部署；不能因本批原神成功而自动勾选。
2. 收敛通用同产物推广/验收能力，维持现有 owner 数量与 URL 合同。Router 共享合同源码仍未部署，现有路由语义等价，不为追齐 Git SHA 无效重发。
3. 修复既有独立游戏站搜索入口：当前三语言 `/{locale}/search?q=` 实际 301 回首页，不是可用的搜索结果页；主站已有搜索能力与独立站入口之间需要明确契约。
4. 独立原神元数据仍有武器标题 `Cosmetic Staffs`、三条 gacha XML URL 指向 hub canonical 的既有例外，calculator 导航与账号边界说明文案也需单独梳理。本批保留基线，不宣称全站 SEO/UX 无问题。
5. 事实运营、性能场数据、跨地域观察、异地完整产物恢复和在线回退演练仍独立排期。搜索引擎收录与官方游戏事实未重新审批。
6. 本批没有磁盘清理、证据删除、服务合并、数据库操作、缓存清除或恢复登录。存储治理应先定保留周期、备份和恢复验证，不能用删掉回退证据换取短期磁盘数字。
