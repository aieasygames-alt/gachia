# S2.8：洛克评级与公开入口范围纠错

日期：2026-10-24，Asia/Shanghai；基线 `81c534f`。本批只在隔离工作树本地开发、验证、提交；不推送、部署、恢复登录、改数据库/Worker 拓扑或清理文件。S2 整体未完成，当前候选仍不可生产发布。

## 1. 目的与证据边界

S2.7 已撤回三只角色复用的数值与九篇攻略的确定断言，但评级、初始精灵/图鉴/战斗/联机攻略以及首页/下载/地图仍会继续传播旧结论。本批修复同一内容的公开消费者，而不是单纯让 JSON 相等或增加免责声明。

未取得新的独立官方 Roco 国际服证据。此前错误的 Steam App ID、本站旧文、国服资料或媒体转述均不能证明国际服名称、技能、平台、测试计划或功能；缺乏证据也不等于取消、不存在或从未公告。保留页面的目的是保存历史阅读和核验路径，不是假装完成事实认证。

原记录、旧 TS 评级模块和涉及旧输出的 28 个公共配置/代码块保存在 [决策档案](../reports/content-integrity/s2-8-source-decisions-2026-10-24.json)。旧国际服输出已撤下或被精确绕过；归档同时包含混用函数中的国服分支及其他游戏仍使用的通用回退，便于追溯，不表示整段代码全部删除。不能把归档中的旧断言重新发布为当前事实。

## 3. 实现与长期维护契约

`roco-public-review.json` 是四个公开入口的主题文案、三项核验条件及两个列表说明的共同输入；TS 策略负责精确匹配国际服四个路由与元数据，组件负责展示，sitemap 调用同一个路由判断。本地浏览器直接读取同一 JSON 核对实际内容，不再维护多份互相矛盾的标题/下载/评级声明。

旧首页简介、每日任务、快捷入口、下载平台/报名链接、地图统计/导流、评级简介，以及四篇攻略对应的八个 Quick Answer/Next Steps 块撤下并归档。已有标记详情防护同时跳过未核实配图、快速回答、培养推荐和相关文章，避免正文修复后从其他消费者再次注入旧承诺。

国服首页/地图仍用原国服分支；地图组件收窄为国服专用，不更改其原文或业务数据。三语双尺寸真实 Worker 验收补国服地图，确认其标题、六个资源入口与自身 canonical 保持可用。其他游戏、独立 Worker owner 与登录停用策略不变。

本批不建设新的服务、CMS 或 Worker。长期继续以“主题源 + 明确审核状态 + 共享派生策略 + 编译后验证”缩小维护面；增加游戏应复用契约，不复制一套硬编码页面。

## 4. 事实 holds 与发布标准

90 对源/镜像全部相等、pending 为零；受管仍为七对共 111 条。两个事实 holds 继续覆盖整份国际服 characters/guides，不因六只角色已标记或十三篇清单重写而自动关闭。held 文件同时修改成相等新值仍会触发快照不匹配；本批在先归档、明确撤回决策后显式更新双端语义摘要与审查文档，不把自动更新摘要加入生成器。

工程快照一致只允许本地开发与审查，不是事实批准。readiness、主站 deploy、upload 的负向测试都必须在构建/上传前退出 1。不得通过清空 holds、绕过包装脚本、放宽 strict 或批量刷新日期来获取“通过”。

恢复确定断言与索引前，须逐项记录来源身份/URL、原文证据与摘要、取得时间、公告/版本时间、区服和平台，完成三语正文与元数据、FAQ、列表、推荐、搜索及 XML 联动验证。审核清单本身不是可据以移除 marker 的官方事实。
