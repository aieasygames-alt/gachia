# S2.16 路径归属合同与 Main 发现路径修复

日期：2026-10-24，Asia/Shanghai。源码基线：`8fa7610`。

## 1. 本批范围与结论

完成 S2.15 的首要阻断修复：不再把部署清单中的独立游戏当成整个 URL 前缀的 owner。
将现有 Router 路径规则提取到共享 JSON，联动主站导航、Main sitemap 和 XML 验收；不改变实际切流规则、公开 URL、数据库或 Worker 拓扑。
重新构建 Main，恢复 NTE 57 个物品详情的三语 171 个发现 URL，覆盖门禁 required 171 / missing 0。
Main 子图从 4,344 增至 4,515，新增集合恰好是这 171 条，移除 0 条；没有以 noindex 或删除数据规避遗漏。

本批完成本地修复与候选验收，**不是线上发布完成，也不是整站可立即部署的结论**。
只读请求另外 85 个公网 NTE 日文迁移边界；没有 push、启动 GitHub Actions、上传/部署 Worker、修改开关、清缓存或恢复账号。
原始脏工作区保持不变，继续在既有隔离工作树交付。本批没有执行磁盘清理，历史证据和生产旧资源不删除。

## 2. 实现与维护合同

| 层 | 变更 | 必须保留的边界 |
|---|---|---|
| 共享输入 | `packages/core/route-ownership.json` 记录独立 owner 的语言、一级目录、详情类别与显式 Main 回退索引类别 | 路径集合与部署/流量开关分离 |
| TypeScript | `route-ownership.ts` 提供 `getRouteOwner`、`isMainSitemapPath` | 未知回退不等于页面存在或可索引 |
| Router | 使用共享路径分类，原 binding、开关、canary、命名空间改写、缓存及 HI3 阅读预览不变 | 不是部署或灰度扩大 |
| Main 导航 | 用实际目标语言与路径判定 native anchor / Next Link | Main 详情可复用 Main；跳独立目录要整页文档请求 |
| Main sitemap | 保留原有审核/语言/退役检查，再按路径归属及显式索引许可过滤 | 不恢复独立 NTE 日文页面、绿梦非中文页面或未知路径 |
| XML 验收 | Python 读取同一 JSON；Main 与独立子图均按真实路径校验，拒绝编码别名 | NTE 子图不能代收 Main 物品详情，禁止将其移除解释成独立 owner 迁移 |
| 封存前覆盖 | 从真实材料源导出三语必需集合，并与路径合同核对 | 少一条或合同冲突都拒绝；原 guard 保留且通过真实新产物 |

NTE `/{locale}/nte/items` 归 NTE，`/{locale}/nte/items/{id}` 归 Main。
绿梦仅中文的既有路径归绿梦；英文、日文继续 Main 回退，但没有自动获得 sitemap 许可。
共享分类描述既定路径 owner，真实请求仍由 Router 的环境开关和 binding 决定；不能拿 JSON 替代独立上线审批。

回归矩阵从 S2.15 的原始 Router 表独立导出，覆盖四游戏、四语言（含不支持的 fr）、首页/目录/详情/过深路径与资产/子图命名空间，共 772 个不同路径。
新 TypeScript 与 Python 实现必须同时满足冻结摘要：
`6f4629fabf35c459f9518341c811c8337762fbd4505af0f82291f355259e08f3`。
既有 Router 测试另外验证开关、灰度、改写和缓存；矩阵等价不冒充已在真实云端部署了新 Router。

未来新增游戏或迁移详情时，同批明确源驱动 ID 清单、语言/审核政策、页面 owner、发现 owner、预计增删、部署版本和回退责任。
不得只增加一个 `deployment: game` 就把整个前缀从 Main 清空，也不得无依据重算矩阵摘要掩盖路由改变。

## 4. 编译内容与导航验收

共享受管内容验收增加全部 171 个详情的真实 HTTP/HTML 断言：200、无重定向、HTML、自身 canonical、index/follow、对应现有源名称、Main 脚本且没有游戏命名空间脚本。
HTTP HTML 用浏览器 DOMParser 解析，不把脚本字符串搜索当作真实 canonical；解析时不执行响应中的脚本。
新增首尾物品 × 三语言 × 桌面/手机，共 12 个浏览器用例；点击回物品目录时必须产生顶层文档请求，不复用 Main RSC。
Main-only 本地夹具不包含独立 NTE 服务，因此浏览器证明跨构建文档边界，Router 直接调用测试证明目标 owner；不宣称已完成真实多服务云端组合联调。

这些断言沿用原有受限云端验收入口。staging 全局 header 要求 noindex，生产拒绝全局 noindex；页面 metadata 的 index/follow 与 staging 隔离分别检查。
云端仍不发送本地夹具 token 或 trusted-IP；本批没有运行新的云端受管内容验收。

实际本地受管验收：浏览器 520、既有 HTTP 边界 23、NTE 全量 HTTP 171、raw 7、搜索 3、本地 IndexNow 8、保留静态资源字节抽样 12，全部通过。
520 包含原有 508 和新增 12，既有撤回/审核内容断言没有删除。发布资产中没有国际服撤回图片或私有审查档案；现有独立国服图片不属于本批新增核实范围。

首次运行因测试选择器同时匹配主导航与面包屑而失败；改为明确选择最后一个返回目录链接后重跑整套通过。
失败记录保留，不改业务页面、不跳过用例、不删除失败证据。
