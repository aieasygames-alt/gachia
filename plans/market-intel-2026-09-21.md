1. **Aniimo 已从上线倒计时切换为上线后承接**：PC/主机 9/16 窗口已经过去，移动端 9/23 即将到来，搜索从 release date 转向 redeem codes、starter、beginner guide、map、Aniimo database、platform/download 和 reviews。站点应把 `/aniimo/version` 从 countdown 改为 launch recap + mobile countdown。

3. **崩铁进入 4.6 前瞻兑换码窗口**：4.5 页面需要从 current live 转向 4.6 special program codes、livestream code deadline、next banner、pull plan 和 team updates。

5. **鸣潮从 3.6 Jingran 过渡到 3.7 预热**：当前站点可继续保留 3.6 Phase 2，但版本页和情报面板应加入 3.7 watch、next banner、codes、map/event 入口。
6. **Roco Global 的 Quack Quack Test 已不再只是第三方信号**：Steam FAQ 与公开资料已经能支撑 10/27 CBT/Quack Quack Test watch 页面，建议从“待核验”升级为“官方/商店页可核验的测试窗口”，但仍不要写成正式上线。
