# 遗忘之海 / 失控进化 内容缺口扫描

日期：2026-07-18

## 结论先看

两边站点都已经有“开服基础层”内容，但缺口不一样：

- `遗忘之海` 现在更缺 **公测后一周的实测层**：
  - 热修/已知问题
  - 地图查漏补缺
  - 号角/返航/大脸币等实操收益
  - 7 月 23 日移动端上线前 FAQ
- `失控进化` 现在更缺 **上线后一周的运营焦点层**：
  - 反作弊 / 非法组队 / 举报入口
  - 自定义模式 / 社区服
  - 电力系统与自动化
  - 服务器周期 / wipe / 模式迁移

换句话说：

- `遗忘之海` 要从“我知道这是什么游戏”往“我现在卡在哪、怎么解决”补。
- `失控进化` 要从“我知道怎么开荒”往“这个服现在怎么活、怎么避坑、怎么跟版本走”补。

## 最该补的内容

## 一、遗忘之海

### P0

1. `7月23日移动端上线 FAQ / 下载入口 / 互通说明`

为什么补：

- 这是接下来 5 天最强的新流量口
- 现有内容分散在 `launch-day-guide`、`platform-download-guide`、`system-requirements-guide`
- 但没有专门针对“7 月 23 日移动端上线”做聚合页

建议页面：

- `mobile-launch-guide`
- 标题方向：
  - 《遗忘之海》移动端 7 月 23 日上线 FAQ：iOS/Android 入口、互通、配置、要不要等手机端

2. `已知问题 / 热修 / 卡死闪退追踪页`

为什么补：

- 当前社区最真实的问题已经不是“值不值得玩”，而是“能不能顺利玩”
- TapTap 里已经出现更新后卡死和流程卡住类讨论

建议页面：

- `known-issues-hotfix-guide`
- 内容结构：
  - 今天已知问题
  - 是否已修复
  - 临时绕过方案
  - 影响平台
  - 最后更新时间

3. `公测实测 Meta 变动页`

为什么补：

- 社区已经在讨论 7 月 16 日小斧头相关机制修复
- 现有节奏榜和配队页更像“开服前 / 开服初版”，还没承接热修后的变化

建议页面：

- `week-one-meta-hotfix-guide`
- 重点写：
  - 7 月 16 日后哪些套路不再适用
  - 茉莉 / 饿猫 / 小斧头 / 铁腕等首周实测环境变化

## 二、失控进化

### P0

1. `安全处罚 / 反作弊 / 非法组队说明页`

为什么补：

- 这是当前社区最强痛点
- 当前站内完全没有专门承接
- 用户不仅关心“有没有挂”，也关心“怎么举报、怎么避免误伤、世界频道为什么限制了”

建议页面：

- `anti-cheat-reporting-guide`
- 内容结构：
  - 官方最近处罚数据
  - 外挂 / 非法组队是什么
  - 游戏内外举报入口
  - 世界频道和私聊限制说明

2. `自定义模式 / 社区服指南`

为什么补：

- 官方 2026-07-15 已开始“自定义”服主招募
- 这是明显的新内容口，但站内尚未覆盖

建议页面：

- `custom-mode-community-server-guide`
- 核心问题：
  - 自定义模式是什么
  - 适合谁开
  - 和标准 / 挑战模式有什么不同
  - 以后赛事服 / 社区服怎么演化

3. `电力系统入门`

为什么补：

- 官方已经主动推这个话题
- 电力属于留存型内容，价值会高于普通新闻

建议页面：

- `electricity-guide`
- 可拆分内容：
  - 风电 / 太阳能 / 炼油 / 灯 / 门禁 / 防御供电

### P1

4. `w i p e / 赛季周期 / 服务器生命周期`

为什么补：

- Rust-like 游戏里，这是高 intent 必问问题
- 当前虽有 S1 时间，但没有专门讲“多久重置、模式周期是什么、独狼什么时候进服最合适”

建议页面：

- `server-wipe-cycle-guide`

5. `非法组队风险与自保`

为什么补：

- 官方处罚里“非法组队”规模巨大
- 用户会担心：
  - 多人临时合作算不算违规
  - 怎么避免被判
  - 举报时要保留什么

建议页面：

- `illegal-teaming-rules-guide`

6. `移动端键位 / 发热 / 团战设置`

为什么补：

- 现有配置页偏总览
- 真正搜索会更像：
  - 三指怎么配
  - 发热怎么办
  - 团战掉帧怎么调

建议页面：

- `mobile-controls-performance-guide`

### P2

7. `首周大事件追踪`

为什么补：

- 现在内容很多是 evergreen，但缺一张“上线后一周发生了什么”的更新页

建议页面：

- `week-one-live-ops-overview`
