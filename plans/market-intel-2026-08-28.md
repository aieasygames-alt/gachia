# Gachia 游戏内容情报采集报告

采集时间：2026-08-28  
覆盖游戏：原神、崩坏：星穹铁道、鸣潮、异环、绝区零、归环、无限大、明日方舟：终末地、遗忘之海、失控进化  
采集范围：近期版本/更新、Google/Bing/Baidu/360 联想词、公开社区/社媒讨论热点  
采样说明：本轮基于公开官网、商店页、社区和搜索联想信号整理。成人、同人、mod、内鬼、解包、破解、私服、非官方下载词只作为规避信号，不建议承接。抓取中出现的 Roco Kingdom / 洛克王国世界暂不属于当前站点游戏范围，本报告不纳入主机会清单。

## 1. 总览结论

相比 2026-08-19，本轮内容机会出现 4 个明显变化：

1. **原神从 7.0 预热进入 7.0 / 至冬上线承接**：Snezhnaya、Nod-Krai、new map、new characters、codes、current/next banner 的搜索应从 watch 口径转为上线后入口。
2. **ZZZ 进入 3.2 特别节目与下一版本预热窗口**：3.1 后半仍有兑换码/平台尾流，但新增机会在 3.2 livestream、new agents、codes、Xbox/Steam/Microsoft Store。
3. **Ananta 最大变化是上线日期与平台口径变清晰**：官方公开口径转向 2027-01-15 全球上线，平台重点是 PS5 / PC / Android / iOS；Steam / Xbox 仍需谨慎核验，不能写成确认平台。
4. **Endfield、Sea、SKJH 从版本新闻转向工具型长尾**：Endfield 继续围绕 Homecoming 后续、蓝图/AIC、测试资格；Sea 的 Steam / release date 信号更偏 2027；失控进化仍是下载、服务器模式、开荒、防抄家。

4. `/ananta/version`：更新 2027-01-15 全球上线日期与已确认平台，纠正 Steam/Xbox 未确认口径。
5. `/endfield/version`：继续强化 Homecoming 后续、测试资格、蓝图/AIC。
6. `/sea/version`：把 Steam / release date FAQ 的时间口径改成更谨慎的 2027 watch。

### 6.2 新增或强化专题

1. 原神：`Genshin Impact 7.0 first steps`、`Snezhnaya / Nod-Krai map guide`、`current and next banner FAQ`。
2. ZZZ：`Zenless Zone Zero 3.2 livestream codes`、`Steam / Microsoft Store / Xbox account FAQ`。

7. 失控进化：`server mode selector`、`base defense anti-raid guide`、`first 0-2 hours route`。

### 6.3 站点治理

1. 搜索框和站内推荐继续过滤 `mod / 内鬼 / 同人 / 成人 / aes key / akt / vicineko / 公益服 / 私服 / 破解版`。
2. 未定档游戏统一使用：`官方暂未公布正式上线日期，以下以官网/商店页为准`。
3. 已定档但未上线游戏统一使用：`官方公布日期为计划上线时间，仍以官网和商店页最终公告为准`。
4. 下载页统一区分：官方启动器、Steam/Microsoft Store、App Store/Google Play/TapTap、主机商店、云游戏。
5. 国际服词单独核验，不把“国际服下载”直接等同于官方海外服。
6. 抓取到站点范围外游戏时，先标记为“候选观察”，不进入当前游戏 backlog。
