## 念处奇旅 (nte) — ⚪ 暂缓（身份存疑）

**问题：** TapTap 搜索"念处奇旅"和"NTE"都无相关结果。
**核查发现：**
- 用户记忆里标注 NTE 为"字节跳动朝夕光年"
- 但 TapTap"NTE"搜索的"猜你想搜"推荐的是《异环》
- 实测《异环》详情页显示开发商为 **Hotta Studio / 完美世界**（非朝夕光年）
- 因此"NTE = 异环 = 朝夕光年"对应链不成立

**站点行动建议：**
- gachia.com/nte 子站暂缓内容生产
- **请用户确认游戏的准确中文名 / 官方英文名 / 发行方**，再决定抓取策略
- 若用户实际指的是朝夕光年/字节系某款特定二游，请提供官网 URL 或 TapTap 链接

## 附录：抓取方法学

- **可用源（headless 浏览器友好）：** 米游社 (miyoushe.com) / TapTap 搜索页 / 大多数官方资讯 HTML 站点
- **不可用源（反爬）：** Bing / Google / 百度 / DuckDuckGo / B 站动态页（要登录）
- **方法：** Playwright MCP 直接 navigate 官方版块 → browser_evaluate 提取 a[href*="/article/"] 链接 + innerText
- **后续可复用：** 此方法学可建立长期监控（每个游戏每周跑一次抓首页新文章）
