# S2.13 国际服兑换码纠错与物品直达边界

日期：2026-10-24，Asia/Shanghai。基线：`6ad78a1`；分支：`codex/multi-game-s1-release-safety`。

## 1. 业务结果与范围

承接 S2.12 已确认的可达消费者风险：撤回国际服兑换码聚合中的旧测试日期、奖励/平台类别、报名优先级和来源背书；将国际服禁用物品路径从首页重定向改为真实 404，并封住通用模板的占位及 metadata 回退。复用现有审核模块，不新增 Worker、CMS、账号、后台任务或发送器。

只在隔离工作树本地开发、验证和阶段提交。没有 push、部署、Actions、生产查询、数据库变更、登录恢复、遥测、拓扑变更或磁盘清理；未修改原始脏工作区。完整修改前七份源码与一次性保护清单见 [来源决策](../reports/content-integrity/s2-13-source-decisions-2026-10-24.json)，具体命令/产物和观测见 [本地验收](../reports/content-integrity/s2-13-local-verification-2026-10-24.json)。

## 3. 编辑和长期维护规则

- 空数组只代表本站没有已收录条目，不能推出官方有效码零、奖励不存在或测试取消。本批没有取得新的官方游戏证据。
- 纠错页不展示数量卡片、兑换口令、奖励表、领取步骤、外链或安装/报名按钮；先验证身份、区服、版本、来源，再分别核对口令、有效期、奖励与领取条件。
- 添加新 raw 记录不会绕过页面审核。恢复需独立证据审批和成套内容、metadata、导航、XML、浏览器回归，不得只删除 noindex 或提前返回。
- 国际服物品列表为不受支持的 URL，不是已有事实文章；使用真实 404 而非新的“资料即将上线”承诺。国服正常访问和既有详情边界保持独立。
- 本批不删除历史图片、原始字段或公开 raw，不声称消除了所有历史分发/缓存。两个事实 holds 和 IndexNow 显式暂停继续保留，工程收敛不能自动转化成生产批准。

新增十二项测试覆盖：审核先于 raw 加载（模拟未来非空数据仍不能绕过）、真实页面 metadata 分支、禁用列表/metadata 的 notFound、空静态参数和详情、国服保留、共享导航及 XML 边界、旧模板撤除和 snapshot CTA。Next 的 JSX preserve 配置不适用于直接 Vitest 导入，测试初次失败后仅改用显式 TS 编译的测试 harness；没有修改生产配置来迁就测试。HTTP、DOM 与实际导航结论另由编译后验收支持，不把 stub 当作真实页面证据。

初次编译验收在 `/zh/roco/items` 发现 301 → 首页 200，立即停止，保留失败记录并增加五项真实中间件分支测试，修正后重新构建和验收；不能把初次结果当作已通过。页面单测未覆盖中间件的教训已纳入编译入口检查。

另外两次中间观测分别纠正了测试对本地重定向 hostname 和 404 robots 单节点的错误假定：Wrangler 可使用同端口 localhost，测试只允许回环且不跟随 Location；Next 的 404 可同时保留继承的 index/follow 和更严格的 noindex，验收实际 404/noindex，且不得生成物品自身 canonical 或物品 hreflang。不是把 404 当作可索引，也没有改生产配置来隐藏测试失败。

源码 AST 比较确认九个非国际服的 description、九个非国际服 instructions、最近公开日/日期格式化、Aniimo/Skjh Hub 和兑换码 section/card 六个 helper 的完整源码与基线一致。这是兼容性检查，不是新增官方事实或实时兑换核验。

主站 XML 从 4,347 降至 4,344，仅撤下三语言国际服兑换码地址，国际服物品列表原本不在 XML。zh/en/ja 为 1,526 / 1,523 / 1,295；当前 Worker 与预渲染集合一致，根索引字节摘要和 owner 均未变。这不是当前生产 sitemap 的检查。实际查看本批中文桌面/手机兑换码纠错与 404 共四张截图：正文自然换行，未见主体裁切；横向栏目导航和英文 404 文案沿用既有行为，不声称逐张查看三语截图。

最终本地产物含 3,146 份普通文件、108,275,254 字节和 19 个内部符号链接；完整文件/链接组合摘要记录在 JSON，三套编译验收针对同一产物。入口文件 hash 不能单独证明完整产物身份，也不是生产封存证明。

保护校验覆盖 185 份 raw、345 份 client/manifest、国服源/镜像、核心注册表、hold 台账及三个旧图片；readiness/deploy/upload 已因两个 holds 在构建上传前拒绝。编译 API 仍仅使用合成令牌与回环地址验收暂停，不读取生产 secret。浏览器阻断外部资源，不能证明 CDN、角色图源授权或实时游戏事实。

## 5. 发布、回退与下一批

本地通过不等于可以生产部署：两个事实 holds、全部 owner 的云端/回滚验收、原神 strict 迁移和独立磁盘治理仍未结案。本批没有发送 IndexNow、恢复旧 API 或执行生产回滚。优先前向修复；若需要回退，应保持纠错和禁用边界，不单独恢复旧奖励 Hub、旧 items CTA 或只恢复 XML。

下一批建议限定审查剩余国际服休眠首页文案与跨区服入口/注册表消费者，追踪哪些仍可触达、哪些只是历史代码，再分别决定撤回、保留或按证据恢复。原始分发及旧图片的授权/留存治理另立有备份和引用保护的工作包，不在常规内容批次顺手删除文件；Worker 合并也继续等待包体、成本和回滚证据，不用内容纠错代替架构决策。
