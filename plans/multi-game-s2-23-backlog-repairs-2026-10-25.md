# S2.23：搜索、肖像与原神页面遗留修复

日期：2026-10-25，Asia/Shanghai。初始基线：`5c42b766755be21e8f40c5934af2ea7f48f3626b`。本记录区分代码、编译验收、云预览和正式发布，不把本地通过当成线上问题已关闭。

## 1. 范围与发布顺序

本批处理已经复现的用户可见问题。只涉及 Main、原神和异环三个实际 owner；不修改共享 Header 代码，因此不要求重发绿梦或蓝色星原。保持现有 Worker 数量、Router 路由、域名、绑定及账号停用边界。

1. Main：实现现有 `/{locale}/search?q=` 入口对应的三语搜索工具页，替代丢弃关键词的 301；复用现有静态索引和噪声词策略，与弹窗共用结果构造、类型排序及最多 30 条限制。结果使用原生锚点，跨 owner 不走客户端 Router。不增加 API、账号、数据库或搜索 Worker。
2. 原神：修正英文武器标题 `Cosmetic Staffs`；计算器补共享导航；中英日首页说明与已停用的登录、收藏和云端同步保持一致；祈愿页改用实际规划内容的独立 title/description、自身 canonical 与对应三语 alternates。
3. 异环：`chaos` 不再请求已确认 404 的肖像。明确展示三语“暂无经核验的角色肖像”，不伪造图像、不借用其他角色立绘。首页卡片与详情共用肖像策略；其他已有肖像路径不变。浏览器验证发现移动端英文 Header 溢出，按原神现有模式允许窄屏换行；修正空数组条件渲染为文字 `0` 的问题；不渲染原数据中全空的技能卡，缺失配装字段明确显示“暂无资料”，不填造游戏事实。

发布依赖是先恢复 Main 搜索目的页，再逐 owner 推广游戏候选。Main 继续使用现有 build → staging → production 同制品工作流及旧资源来源门禁；游戏候选采用既有服务的 version preview，验收后推广同一 UUID，不创建 staging Worker，不在推广时重建。

## 2. URL、SEO 与资源合同

- 搜索是交互工具，`noindex,follow`，canonical 不含查询参数；不进入 sitemap，不给任意关键词制造可索引页。保留查询初值、普通 GET 表单和真实无结果状态；索引失败明确报错并可重试；脚本关闭时提供说明和可点击的首页入口。搜索仅覆盖现有索引，未承诺所有游戏及所有内容已被收录。
- 新旧搜索弹窗共用相同规则，保留 HI3 武器公告的适用范围提示。关键词最多 160 字符；超长 URL 查询拒绝匹配，不进行不受限扫描。
- 祈愿页已有独立的决策步骤、预算/保底核对与参考链接，不是首页副本，因此保留现有三条 XML URL，将其 canonical/alternates/标题修正为该页，而非删除 XML 或对所有页面盲目改成自身 canonical。兑换码、缺译攻略等其他索引例外不变。
- 本批不修改任何 sitemap 集合；正式目标仍是 Main 4515、原神 1572、异环 389、蓝色星原 150、绿梦 27，共 6653 唯一 URL。Main 承接的 171 个 NTE 物品详情不变。
- `chaos.webp` 原路径本身不会凭空变成有效图像。本批关闭的是现行 NTE 渲染器的缺图请求；旧 HTML/历史外链仍可能请求该 404。取得可追溯、身份已核验且可合法使用的肖像前，不填入猜测资源。
- 旧浏览器可能保留历史 301；本批不清除 CDN 或用户缓存，也不修改其他 owner 已发布 Header。

## 3. 实际验证与证据

只读线上基线保存于 `.release-records/s2-23/baseline.json`：搜索 301→首页、缺图 404、原神错误标题、gacha 指向 hub canonical、calculator 无共享 Header 均已复现。九个服务生产/staging 版本与 S2.22 收尾一致。

本批增加 `scripts/backlog-repairs-smoke.mjs`，只接受显式 loopback Worker，不会部署云端。覆盖三语言、桌面/手机、搜索初值/筛选/空结果/失败重试、原生文档导航合成目的页、无 JS 说明、原神导航和异环占位。合成目的页只验证导航语义，不冒充真实其他 owner 页面验收。

已有发布测试、常规单元测试、type-check、lint、实际编译 Worker、受管内容与 XML、账号停用/运行时、原神缺译策略的检查继续保留。所有失败证据保留，最终实测数字和云端放行状态在阶段收尾时补齐。

已保留的初轮问题：HTTP 检查误将 Next 自身普通 script 标签当作查询注入，改成精确恶意查询载荷断言；Playwright 对 noscript 容器的 text matcher 返回空，改为检查无 JS 下实际可见段落和 body 阅读文本；NTE 既有 `.detail-image:not([src])` 规则误隐藏 div 占位，收窄到 img；英文窄屏 Header 实测宽度 424/390，修复而非忽略溢出断言。这些不是线上发布失败，没有为修验收工具而重新部署。

## 4. 存储与运营遗留边界

本批仅做当前隔离工作树只读容量清单，不删除文件。测得约 2.84 GiB 的 `.release-records` 包含封存产物、权威云模块、回退来源、失败记录等，不是可直接清理的缓存；`node_modules` 约 1.98 GiB 可由锁文件重装，但正式验收/本地预览使用中不删除；`.next/.open-next` 仅在未被封存/运行进程引用、来源和恢复路径已确认后才能作为重建目录处理。不能把当前隔离工作树统计当成整台机器或原始脏工作区完整清理审计。

尚未自动关闭：独立生产审批/分支保护、历史部署入口统一门禁、在线兼容回退演练、异地完整产物恢复、受保护证据保留周期与获准清理、全站内容事实复核、真实用户性能/跨地域观测及是否合并 Worker 的成本实验。它们需要各自验收，不能用一次 UX 修复或部署成功替代，也不为短期磁盘数字删除唯一恢复证据。
