核验日期：2026-10-15（Asia/Shanghai）。本轮为源码、内容、代表线上入口和公开官方来源检查；不是全站完整功能回归。没有修改业务代码、安装依赖、运行构建或部署。保留工作区已有修改与未跟踪文件。

## 项目概况

- pnpm 10.10 / Turborepo monorepo；Next 15.5.18 / React 19 / TypeScript；Cloudflare Router + 主站 Worker + 游戏独立 Worker。
- apps/web 为主站；genshin、nte、azur-promilia、lvmeng 四个独立游戏应用均在 packages/core/deployments.ts 标记 live。admin 是本地内容工作台，不能等同线上后台或全自动发布平台。
- packages/core、data、db、ui 为共享模块。主站资料主要在 apps/web/public/data 与 apps/web/lib；绿梦直接使用 apps/game-lvmeng/lib/data.ts，不走主站 raw-guides 数据目录。
- 共注册 16 个游戏 ID；roco 与 roco-cn 是不同市场，不应混用服区公告。绿梦仅简中。
- 当前进度入口为 plans/project-task-status-current.md：HI3 阅读发布已关闭，本地手动工作台仍有端到端验收与源码卫生待办。不要把这些待办混入本次内容补充。

## 二、发现的工程与收录缺口

- P1 sitemap：apps/game-lvmeng/app/sitemap.ts 只列 14 个静态入口，漏掉 9 个可访问角色详情；lastModified 固定 2026-09-25。线上专属 sitemap 同样没有 /characters/ 条目。应从角色数组生成详情 URL，并使用真实内容更新时间；缺 sitemap 不等于已证明未被索引。
- P1 新鲜度审计盲区：scripts/content-freshness-audit.mjs 只遍历 13 个数据游戏，未覆盖 lvmeng / azur-promilia / hi3；也未扫描独立 Worker 资料与 three-game-status。现有匹配规则不能检测已过去的前瞻、10/31旧日期、upcoming状态。此次返回 0 risk / 110 archive 不能作为全站事实正确证明。
- P1 smoke 误报：apps/game-lvmeng/scripts/smoke.mjs:43 用 includes('Disallow: /')，会将正常的 Disallow: /api/ 判为全站屏蔽。对公共主站执行实际在此失败；robots 当前 Allow: /，不是实证全站禁爬。
- P1 smoke 作用域：脚本设计面向独立 Worker origin，末尾读 /sitemap.xml；对 Router 公共域名应另测 /sitemaps/lvmeng/index.xml，不应混淆主站 sitemap 与游戏 sitemap。
- P2 主站路由能力标记：core 的 lvmeng characters/map=false，而独立站已有页面。需检查游戏导航和发现入口是否有意隐藏薄内容，不宜未经检查直接全开。
- P2 内容模型：为状态/截止时间加结构化字段与过期提示，主站和独立站共享已确认基础事实，避免多份手写日期长期漂移；不要求本轮重构整个平台。

## 四、本轮检查结果与边界

- pnpm validate:game-deployments：通过，4个Router游戏部署配置。
- pnpm --filter @gachia/game-lvmeng type-check：通过。
- pnpm content:freshness --json：0风险、110归档匹配；存在前述覆盖盲区。
- LVMENG_ORIGIN=https://gachia.com pnpm --filter @gachia/game-lvmeng smoke：失败于robots子串误判；在失败前脚本列出的6个游戏内容入口、robots和主站sitemap均200，canonical/资源前缀/无hreflang断言通过。
- Node fetch代表路径：首页、洛夕/艾提/玛塔详情、游戏专属sitemap、OG图均200；首页仍公测准备；sitemap角色条目为0。
- Python urllib请求同站出现403，但Node请求相同路径200，属于请求客户端差异证据，不能据此判站点整体故障；本轮未完整浏览器回归游戏站、未验证所有静态资源/每个角色/真实账号与游戏客户端。
- 不构建：当前任务状态文档提示本机依赖补丁状态有风险，本轮不为内容审计重新安装或生成生产包。
