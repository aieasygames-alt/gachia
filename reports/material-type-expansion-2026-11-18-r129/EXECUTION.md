# R129：跨游戏材料依赖与消费者门禁

日期：2026-11-18。状态：开发与审计完成；未扩大材料正式发布资格，未新增生产部署。

## 已交付

从用户指定的 R128 最终索引接续，完整历史 reader 前后两次重读通过。
115 份已发布来源的摘要保持，胡桃、咲里与既有攻略增量沿用公开 A。
正式 NTE 版本仍为 `1c4ccf07-2744-443b-b0a0-bcccbb20cdbb`；本批没有
CMS 编辑、上传、部署、回滚或来源推进。

新增六种实际材料关系格式的共享依赖校验，覆盖全部 13 个 raw 材料域。
保留每次引用的 JSON 指针和数量，检查材料/角色身份、重复身份、完整组结构、
正安全整数数量及 NTE Zero 的两个已核准展示变体。

新 CMS 来源冻结在创建工作区前执行门禁：材料定义或材料关系变更必须达到完整
依赖闭合；既有角色文本变更不得引入新依赖问题。保留公开 A 的 overlay 不被
误当成本批新修改。冻结回执记录依赖摘要，独立重读重新计算；历史回执保持可读。

材料变更的 owner 构建自动加入全部材料详情与列表页的源派生断言，包括实际名称、
关联入口、适用的反向角色链接、canonical 和 robots 策略。审核者不能用无关页面的
成功断言替代。NTE 日文列表沿用明确的 noindex，日文材料详情保持可索引。
鸣潮反向角色关系来自 inline 字段，仍需要单独的消费者适配；本批没有假定它与
`raw-character-materials.json` 等价。

## 审计更正

原 R128 统计只看得到有 ID 的材料引用，因此“12 个无缺失”不足以放行材料类型。
本批结果为 10 个域结构依赖闭合、2 个阻塞、1 个空材料域。结构闭合不代表游戏事实
核验或正式发布资格。

| 游戏 | 材料定义 | 关系引用 | 阻塞 |
|---|---:|---:|---|
| 原神 | 185 | 5,400 | 74 个未定义材料 ID，涉及 1,775 次引用；另有 4 个未匹配角色 ID |
| 归环 | 20 | 408 | 108 条只有数量、没有材料 ID；旧统计仅计入了另外 300 条 |
| 异环 | 57 | 42 | 无材料或角色悬空引用；Zero 两个页面身份保持 |
| 洛克王国全球域 `roco` | 0 | 0 | 空材料目录，不作为已资格化材料域 |

原神逐条审查队列包含所有引用指针。3 个材料有明确的本地命名候选：
`callalily → calla-lily`、`oni-kabuto → onikabuto`、
`slime-Condensate → slime-condensate`；角色 `sara`、`shinobu` 各有完整 ID 候选，
`mualani`、`ororon` 尚无对应记录。候选均未自动批准或改写；未把异环的删除授权
套用到原神或归环。

## 公网消费者证据

最终 `public-03` 保存了 138 个真实 GET 响应：21 个材料/关系 JSON，3 份全站聚合
搜索，36 个列表，78 个代表性详情。全部 HTTP 200；公开 JSON 与 R128 对应输入
解析值一致，已有材料搜索投影逐项比较。

消费者门禁结果为 **blocked-by-consumer-gaps**，CLI 按合同返回 2。这是已完成的
阻塞审计，不能记为材料可正式更新。发现三个实际应用缺口：

1. 终末地三语材料列表卡片是普通 `div`，没有材料详情链接。
2. 星铁三语列表固定分类顺序未包含 `special`，例如命运的足迹已有详情与 JSON，
   却不出现在材料列表入口。
3. `roco-cn` 材料没有进入三语全站搜索 scope。

第一轮遇到缺失链接时停止并保留 `public-01/failure.json`。随后补成独立只读观察
全部完成、失败仍阻塞的审计。第二轮把 NTE 日文列表 noindex 误判为缺口；核对
`indexing-policy.ts` 后按既有策略修正合同，最终只剩上述三类真实缺口。
没有放宽链接断言，也没有修改线上 SEO 策略。

本次只采样详情，未宣称全部材料详情、sitemap、媒体或字段已完成资格化。
公开消费者探针与完整 owner 构建合同共用同一个源派生验证器。
