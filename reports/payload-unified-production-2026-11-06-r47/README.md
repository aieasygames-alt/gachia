## 已实现

- `unifiedEditorialScope` 独立比较 A→B 和 O→B：真实 Ananta 编辑仅涉及 Main；原神/异环为保留公开 A 的 overlay。缺失保留文件、夹带未申报变更、漏掉编辑或未知身份均拒绝。现仍保守保留三个上传 owner，没有凭分类结果授权省略活动游戏运行时。
- 固定生产入口 `unified:production audit-local|audit|upload-previews` 只接外部 pin 的选择、完整 A、审核/冻结/预览、安装应用清单和源交接。拒绝调用方注入 verifier/transport、skipCI、ownerOrder、promote 或“已通过”标记。
- 本机正式审核从固定 loopback REST 重新读取，要求 reviewer/admin、published、hold=false，核对游戏关系和不可变来源；共享桌面选择校验，三方重新编译必须与封存候选完全相同。预检前后重读审核，校验当前安装清单、精确 Git 源文件和构建 ID。
- 云预检强制通过当前 `gh` 认证读取固定私有仓库/分支/工作流的精确完整 CI，令牌不进入请求 JSON 或日志，跳过的消费者步骤不能代替成功。执行器必须无未提交代码且逐文件匹配当前提交；当前活动 UUID、七服务拓扑/绑定/预览设置和原始模块证据重新读取验证，不把 R45 的时间改成现在。
- 固定上传适配器只使用已验 Wrangler、封存 `--no-bundle` 模块和正确环境，先恢复再候选；上传响应 UUID、上传时 multipart、强 ETag、不可变版本、精确云 Host 全路径响应和独立重验相互绑定。独占单次 journal，未知结果停机并只读对账，无自动重试、自动回滚或部署入口。
