# R62 真实生产预检组合

## 实现

- 将生产预检的云身份组合整理为内部 `unified-production-verifier.ts`。原固定入口仍验证严格参数并执行单机/精确执行器检查，没有新增依赖注入字段或 CLI 写入权限。
- 原入口在异步模块加载前固定请求与原执行器选项，防止等待期间调用方更换历史执行器身份。
- 移除推广组合对整个 `createUnifiedProductionVerifier` 的成功替换。现在真实执行当前/源/原执行器 CI、真实 Git 字节守卫、七服务拓扑、五 owner 来源交接与模块身份、已审核配置及 multipart 元数据、release key 计算和每次写前/写后复验。
- 本机安装/CMS 审核组合 `verifyUnifiedProductionLocal` 仍被隔离返回。测试使用合成封存产物和网络响应，不把这个边界声明为已验证的真实生产资格。
- 修复异步版本/拓扑读取后的执行器复查缺口：每次 verify 完成前及初始最终拓扑读取后再次检查源码，避免读取期间发生的源码变化仍返回预检成功。
- 推广打开阶段新增完整源 CI/原执行器 CI 与历史审核的相等检查，拒绝相同 run ID/commit 但重跑次数不同的结果，防止切流成功后生成无法被历史 reader 接受的收据。

## 测试

推广组合由六项扩为十七项。新增源 CI 不完整、来源交接 pin 变化、非 Main 不可变版本变化、云配置变化、multipart 元数据错误、本机审核拒绝、写后审核变化、请求/原执行器选项异步修改、版本读取期间真实临时 Git 源码漂移，以及源 CI/原执行器 CI 重跑次数不匹配。

重复调用现在先受真实来源拓扑检查拒绝；即使模拟云状态回到原基线，原推广日志仍拒绝重放。成功用例继续独立重读完成态，并消费 115 来源。失败不生成成功收据，不自动重试或回滚。

初始十三项定向用例通过；后续四项定向用例也通过。首轮 CMS 363/363（固定组合 114/114）通过；添加最终 CI 身份检查后重新执行全量，最终 CMS 363/363（固定组合 116/116）通过，零跳过，耗时约 326 秒。最终日志见 `cms-final.log`。共享协议 197/197、文档/scope 38/38、类型检查和差异空白检查通过。

磁盘约剩 27 GiB，复用现有依赖和封存数据。没有复制大型工作台或删除发布证据、备份及常驻安装；测试临时目录正常清理。
