## 工程变更

- 独立桌面 `unified-import` / `unified-export` / `unified-freeze`，不放宽原隔离 SQLite 入口。导入必须指定游戏范围与完整来源计划 pin；正式导出必须指定 1-200 个已登记记录，以及选择清单和完整公开 A 的独立 pin。
- 只允许当前已安装应用访问固定桌面数据库；源码 checkout、暂存安装、CI、远程 editor、fixture 和 preview 入口均不能替代。
- 正式选择从 Payload 重读 published / hold=false，核对实际 game、完整来源信封、结构规则及批准值摘要；准备后再次读取，批准版本漂移则拒绝。输出只作为编辑候选，不授权上传或推广。
- 已修复 Payload 全语言读取返回空 title/body 语言对象导致的错误拒绝；非空内容、未知语言仍拒绝，不能建立第二份编辑内容。
- 来源读取明确接受所选仓库，不再从安装应用的父目录寻找游戏数据。原隔离调用的默认行为保持。
