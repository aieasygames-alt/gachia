- 公网 URL 契约存在两项边界差异，尚不能归为应用漏洞：`/zh/%00` 返回 Cloudflare 品牌 HTML 400，没有应用的 no-store/noindex；`/zh/%2Ehidden/%2E%2E` 返回 308 `/zh/`，最终两跳至 `/zh` 200，而不是应用预期的非法点段 400。前者有边缘响应证据，后者的精确归一化层尚未定位。没有观察到绕过权限或重定向循环。后续需明确公网入口与应用层各自契约，不把本地断言直接当作公网保证。
- 测试误报已核对：编码 ASCII 路径返回相对 Location `/zh/about?source=online-verification`，与原断言的绝对 URL 等价；实际跟随一跳到同源 200，查询参数保留。这不是产品缺陷。保留原始 `http.json` 断言失败，不覆盖为全绿结果。
