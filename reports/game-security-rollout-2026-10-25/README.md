## 差异与来源

四款游戏相对各自历史发布记录中的源码，应用目录没有新增变更；共享 schema、依赖与工具链有变化。重新读取四个当前 100% 生产版本和权威 Worker multipart，核对版本 etag，捕获前后部署、绑定、路由与域名一致。当前模块摘要与历史已保存的模块证据相符。

四个本地候选与当前线上 Worker 字节不同，Zod 相关运行时代码也存在变化，因此不能仅凭页面源码未改就跳过候选验收。字符串标记只用于定位差异，不构成完整 SBOM 或线上漏洞可利用性证明。旧 Git 来源仍按历史操作记录表述，不升级为平台签名的源码证明。

原神、异环、绿梦分别重新取得当前版本绑定的 82 / 88 / 68 份旧静态文件，下载核对字节后保留于新候选。三个候选从干净、已推送源码重新构建，封存整个 portable Worker 树，记录外部 manifest 摘要；执行配置位于封存目录外。旧资源完整性是已登记清单范围，不声称取得了 Cloudflare 全部历史资产清单。

## 失败记录与尚未完成事项

### 绿梦：上传阻断

封存候选 manifest `2991d7af7524e93c47fedfda8c4610de8e43e72910a3d049951ba0a4fb6ea582` 的本地门禁已通过。

上传前还有一次本地验收文件映射断言失败：检查器未解码 URL 中的 `%5B/%5D`，无法匹配封存清单路径；修正为解码后精确核对 SHA-256 才继续。该次在远程操作前退出，不算额外上传。此映射修正未改变资源字节或放宽摘要断言。

后续需先处理上传 API/网络可达性，重新核验云端版本与完整候选来源，再进行预览与正式验收。当前候选仍绑定 `bab9e32`，本报告提交不代表候选重新构建；后续不能将新 HEAD 冒充该候选源码。

### 蓝色星原：运行时防索引与同制品推广待补齐

该应用没有其他三款使用的 runtime preview-host middleware，robots/header 依赖构建模式。对现有直连域名的 GET 实测：`/robots.txt`、`/sitemap.xml`、`/zh/azur-promilia` 均 200，无 X-Robots-Tag；robots 为 Allow `/`，主页 canonical 指向正式域名。这不等于搜索引擎已经收录，但不能满足同一生产包在直连/版本预览域名禁止索引的门禁。

本批未上传或改变蓝色星原。后续需补运行时 hostname 防索引、真实编译产物与 Host 防伪测试、严格封存配置及旧资源/回退兼容，再使用同一制品进行预览和正式推广；不能只用 preview 模式重新构建来冒充生产包验收。
