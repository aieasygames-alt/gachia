# Next deferred initial-value candidate

## Current pilot runtime: Next 15.5.28

NTE and Azur Promilia use the exact Next 15.5.28 / OpenNext 1.20.13 /
Wrangler 4.148.0 combination. Other apps retain Next 15.5.18 and its original
patch registration until their separate runtime acceptance. Node 22+ is required.

`next-15.5.28-deferred-initial.patch` is a separately verified port of the same
four absent-prefetch fallback changes. The patch bytes happen to be identical;
the distribution source digests are not. Its adjacent JSON manifest records
the new original and patched digests. Never use a version range to select a
manifest or reuse the old source hashes. The verifier resolves the app's package
and accepts only one of the two exact reviewed versions, rejecting partial or
drifted sources. The pilot build gate additionally checks exact adapter/CLI
versions and retains the caller's indexing mode.

Local runtime and browser acceptance is documented in
[S1.1 closeout](../plans/multi-game-s1-runtime-closeout-2026-10-23.md).
This is not cloud acceptance or approval to deploy the patch to production.
Original source maps remain unchanged and must not be treated as accurate
mappings of the four patched source files.

## Legacy Next 15.5.18 baseline

Status: package-manager registration and lockfile integrated after limited local acceptance.
The main checkout dependency directory has NOT been reinstalled and still contains original Next files.
No production deployment is authorized or accepted.

`next-15.5.18-deferred-initial.patch` contains four one-line replacements in the
CJS and ESM layout/head routers. Only absent-prefetch initial values become
`undefined`; prefetched values, React internals and error recovery are unchanged.
The change affects the shared Next router, not only HI3. Its effect on prefetched
client navigation, other games and uninstrumented delayed hydration is not yet
fully covered. The original source-map files are unchanged; do not treat them as
accurate mappings of the patched sources. Rebuild from the patched sources.

Run the read-only gate from the repository root:

```sh
node scripts/verify-next-deferred-patch.mjs
node scripts/verify-next-deferred-patch.mjs --require-patched
node scripts/verify-next-deferred-patch.mjs /absolute/path/to/isolated/next
```

For this legacy manifest, the gate accepts only Next 15.5.18 with all four original or all four patched
digests. It rejects partial application and source drift. It never writes files.
The adjacent JSON manifest binds the patch and expected source digests.

Local evidence: `reports/workbench/hi3-deferred-runtime-decision-05.json`.
One instrumented Chinese directory delay comparison improved from 13,752 target
reconcile throws to one; three-language no-JS reading and Chinese desktop/mobile
search passed. This is not all renderer work, complete authentication acceptance,
current-tree content approval or production staging. Authentication logged a
missing synthetic secret, and earlier build tool auto-preparation is recorded.

`package.json` now registers this patch and `pnpm-lock.yaml` contains the hash
generated by pnpm 10.10.0 offline. No package versions or resolutions changed.
The independent installation, 154 web tests, types, build and 97 local runtime
checks passed; see `reports/workbench/hi3-pnpm-integrated-runtime-01.json`.
Three shared client navigations (hover before click) and one Genshin page passed;
actual prefetch request coverage was not measured. Empty-session API returned 200
with a random synthetic secret. OAuth and trusted-IP warnings remain; one workerd
broken-pipe log is recorded, not dismissed as a proven harmless event.

Main checkout builds MUST NOT be treated as patched until resolved dependencies
are refreshed via the approved package manager and the read-only gate reports
`patched`. Do not mutate the existing pnpm store or copy patched files into it.
No auto-apply hooks were added. Production adoption still requires final current-
tree review, immutable build delivery, package/cache and staging/rollback gates.
