# Next deferred initial-value candidate

Status: package-manager registration and lockfile integrated after limited local acceptance.
The main checkout dependency directory has NOT been reinstalled and still contains original Next files.
No production deployment is authorized or accepted.

`next-15.5.18-deferred-initial.patch` contains four one-line replacements in the
CJS and ESM layout/head routers. Only absent-prefetch initial values become
`undefined`; prefetched values, React internals and error recovery are unchanged.
The change affects the shared Next router, not only HI3. Its effect on prefetched
client navigation, other games and uninstrumented delayed hydration is not yet
fully covered. The original source-map files are unchanged; do not treat them as
accurate mappings of the patched sources. Rebuild from the patched sources.

Run the read-only gate from the repository root:

```sh
node scripts/verify-next-deferred-patch.mjs
node scripts/verify-next-deferred-patch.mjs --require-patched
node scripts/verify-next-deferred-patch.mjs /absolute/path/to/isolated/next
```

The gate accepts only Next 15.5.18 with all four original or all four patched
digests. It rejects partial application and source drift. It never writes files.
The adjacent JSON manifest binds the patch and expected source digests.
